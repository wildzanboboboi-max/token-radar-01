How implied value is computed

One function scores every protocol. No name is special-cased and no row is hand-picked.

  • Comparable. The median market-cap / TVL of live-token protocols in the same category (at least 4 of them), shrunk toward the overall median and clamped to 0.05–0.65. Thin categories fall back to the overall median.
  • Growth. The 7-day TVL change, clamped to −50%…+100%, weighted 0.6. A shrinking protocol is worth less than its TVL alone suggests.
  • Maturity. Days since first listed, up to 3 years: 0.65 + up to 0.35. A protocol that has run longer with no token has more to launch — and the longer it runs unlaunched, the more the risk list says so.
  • Breadth. +1.5% per extra chain, up to 8 chains. Multi-chain TVL is harder to lose in one place.
  • Farm plans. Six steps each, derived from the protocol’s category, chains, TVL and age — with a cost and a time on every step. Never pay to claim; claim only from a link the protocol itself publishes.
  • Risks. Heuristics from the snapshot alone (single-chain, cooling TVL, very young or very long unlaunched). The snapshot carries no holder, contract or liquidity data, so these are not on-chain checks.

What this radar does not do: it does not predict whether or when a token is issued. A board’s implied value is this entry’s own claim, never the market’s.
